# Vedika Studio – template covers + components

    npm install
    npm run dev      # http://localhost:5173

- `public/covers/`  14 template covers (id = filename)
- `public/assets/`  48 individual transparent assets (category-name.png)
- `src/data/templates.js`  add/edit templates here (title, category, palette, elements, floorPlan)
- `src/data/assets.js`     asset library list
- Components: Sidebar, Topbar, TemplatesPage, TemplateGrid, TemplateCard, AssetLibrary, DesignStudio
